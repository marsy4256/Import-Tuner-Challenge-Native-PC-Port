# Import-Tuner-Challenge-Native-PC-Port
Experimental native PC port of Import Tuner Challenge using the ReXGlue framework and PGR4-Recomp static recompilation pipeline.  Status: Highway gameplay is functional. Known crash occurs when exiting the Time Attack Record menu.  Released open-source for the community to polish. Huge thanks to the ReXGlue and Xbox 360 recomp team!
